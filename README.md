Dit is de Git voor de code voor een MIDI controller die ik gemaakt heb. Deze MIDI controller zorgt ervoor dat je met geluiden een beat kan maken. De controls zijn simpel:
1,2,3: sample select
4,5,6: drum select
Met de muis kan je de overige controls besturen. Dit zijn de sfx en de sample chops linksboven. 
Ook is er een "over mij" pagina die mijn motivatie beschrijft.

In de index van de code staat de MIDI controller.
